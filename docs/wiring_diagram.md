# 手套端接线图与引脚分配

> 目标板：**ESP32 DevKit V1（30 针）**
> 与代码的对应关系：[IMU_Car.ino](../code/arduino/IMU_Car.ino) 第 1 节 `PIN_*` 宏。**改线必须同步改代码**。

## 1. 一眼看懂的接线表

### 1.1 ICM20689（I2C）

ICM20689 是**双接口**器件（SPI + I2C 共用引脚），不同模块的丝印命名不一样。命名对照先看清楚：

| 模块丝印 | 另一种常见丝印 | 本表统一叫法 |
| --- | --- | --- |
| `SDA` | `SDI` / `MOSI` | SDA（I2C 数据） |
| `SCL` | `SCLK` / `SPC` | SCL（I2C 时钟） |
| `SDO` | `AD0` / `SA0` | SDO/AD0（地址选择） |
| `CS` | `CSN` / `NCS` | CS（片选，**I2C 模式下必须拉高**） |
| `INT` | `INT1` | INT（中断，本项目不用） |

| ICM20689 引脚 | 接到 ESP32 | 说明 |
| --- | --- | --- |
| `VCC` | **3V3** | ⚠️ 不是 5V。ICM20689 是纯 3.3V 器件（1.71~3.6V），多数模块**没有** LDO 保护 |
| `GND` | **GND** | 必须共地 |
| `SCL` | **GPIO22** | I2C 时钟 |
| `SDA` | **GPIO21** | I2C 数据 |
| ⚠️ `CS` | **3V3** | **最关键的一根线**：芯片靠 CS 电平选接口。拉高 = I2C；悬空/拉低 → 一直等 SPI，I2C 永远无应答 |
| `SDO/AD0` | **GND** | 决定 I2C 地址：接 GND = `0x68`，接 3V3 = `0x69`。代码默认 0x68 |
| `INT` | 悬空 | 本项目用轮询，不用中断 |

> **如果模块只有 SPI 引出（很多 ICM20689 是飞控拆机件）**：那就必须走 SPI，不能用本表。此时硬件默认就是 SPI 模式（CS 由主机控制），本固件第 6 章的 I2C 读写函数需改成 SPI 实现——工作量约 40 行，见 [debug_faq §3.1](debug_faq.md) 与 [code_walkthrough §5.2](code_walkthrough.md)。**先确认你手上的板子到底有没有 I2C 引出**（看有没有 SDA/SCL 或 SDI/SPC 丝印）。

### 1.2 nRF24L01+（SPI）

| nRF24L01 引脚 | 接到 ESP32 | 说明 |
| --- | --- | --- |
| `GND` | **GND** | **必须第一根接的线**，且尽量短 |
| `VCC` | **3V3** | ⚠️ 绝对最大 3.6V，接 5V 直接烧毁 |
| `CE` | **GPIO4** | 收发使能，代码里由 RF24 库控制 |
| `CSN` | **GPIO5** | 片选（低有效） |
| `SCK` | **GPIO18** | SPI 时钟（ESP32 VSPI 默认） |
| `MOSI` | **GPIO23** | 主出从入 |
| `MISO` | **GPIO19** | 主入从出 |
| `IRQ` | 悬空 | 本项目不用中断 |

### 1.3 板载资源（无需接线）

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 状态 LED | **GPIO2** | 板载蓝色 LED：常亮=标定中，心跳闪=正常，快闪=射频异常 |
| BOOT 按键 | **GPIO0** | 短按=切换 DRIVE/GIMBAL，长按 1.5s=重取水平基准 |

## 2. 接线示意（面包板阶段）

```
                        ┌───────────────────────────────┐
                        │        ESP32 DevKit V1        │
                        │                               │
    ┌───────────────┐   │  3V3 ────────────────┬────────┼──────────────┐
    │   ICM20689    │   │                      │        │              │
    │   (ICM20689)  │   │                      │        │    ┌─────────┴────────┐
    │               │   │                      │        │    │   nRF24L01+      │
    │  VCC ─────────┼───┤                      │        │    │                  │
    │  GND ─────────┼───┼─── GND ──────────────┼────────┼────┤  GND             │
    │  SCL ─────────┼───┼─── GPIO22           │        │    │  VCC ────────────┤ (3V3)
    │  SDA ─────────┼───┼─── GPIO21           │        │    │                  │
    │  CS  ──── 3V3 │   │                      │        │    │  CE  ── GPIO4    │
    │  SDO/AD0 ─ GND│   │                      │        │    │  CSN ── GPIO5    │
    │  INT ── 悬空   │   │                      │        │    │  SCK ── GPIO18   │
    └───────────────┘   │                      │        │    │  MOSI ── GPIO23  │
                        │                      │        │    │  MISO ── GPIO19  │
                        └──────────────────────┴────────┴────┤  IRQ ── 悬空     │
                                                             │                  │
                                                             │  ┌───────┐       │
                                                             │  │ 100µF │  ← 关键！
                                                             │  └───┬───┘       │
                                                             │   VCC┴GND        │
                                                             └──────────────────┘
```

### 2.1 去耦电容的正确接法

```
     3V3 ──────┬──────────── nRF24L01 VCC
               │
            ┌──┴──┐
            │ 100µF│   ← 电解电容：长脚(+) 接 3V3，短脚(−) 接 GND
            └──┬──┘      注意极性！接反会鼓包炸开
               │
             ──┴── GND
```

**三个要点**：

1. **电容必须尽量靠近 nRF24L01 的 VCC/GND 焊盘**（引线长度 < 2cm）。放在面包板另一头等于没装。
2. 大电容（100µF）+ 小电容（10µF 或 0.1µF 陶瓷）**并联**效果最好：大电容管低频冲击，小电容管高频。
3. 如果模块还是复位，说明面包板接触电阻太大——**直接焊在洞洞板上**，或改用 AMS1117-3.3 模块单独给 nRF 供电（见 [hardware_list.md](hardware_list.md) §1.2 A16）。

## 3. 引脚分配的设计理由

### 3.1 为什么是这几个脚

| 引脚 | 用途 | 为什么选它 |
| --- | --- | --- |
| GPIO21 / GPIO22 | I2C SDA/SCL | ESP32 的**默认 I2C 引脚**，`Wire.begin()` 不填参数也能用；且不属于 strapping 脚 |
| GPIO18 / 19 / 23 | SPI SCK/MISO/MOSI | ESP32 的**默认 VSPI**（又称 SPI3）总线；GPIO18/19/23 是硬件固定映射，能用 DMA |
| GPIO5 | SPI CSN | VSPI 默认 SS 脚，与 SPI 硬件外设天然配套 |
| GPIO4 | nRF CE | 普通 IO，非 strapping、非 ADC2，任意可用 |
| GPIO2 | 状态 LED | 板载 LED 本来就接这里 |
| GPIO0 | 按键 | 板载 BOOT 键本来就接这里（见下方警告） |

### 3.2 必须避开的引脚（踩了就后悔）

| 引脚 | 问题 |
| --- | --- |
| **GPIO6 ~ GPIO11** | 接内部 SPI Flash，**一用就死机**（这是最常见的"引脚选错"事故） |
| **GPIO34 ~ GPIO39** | **只能输入**，没有输出能力，不能驱动 CE/CSN |
| **GPIO0 / GPIO2 / GPIO5 / GPIO12 / GPIO15** | strapping 脚（上电电平决定启动模式）。本项目只把 CE/CSN/LED/按键放这里，因为都是"上电后才有意义"的信号 |
| **GPIO12** | 上电被拉高会导致 **3.3V Flash 供电异常，无法启动**。绝对不要用它做输出 |
| **GPIO1 / GPIO3** | UART0 的 TX/RX，占用后串口打印就没了 |

> **本项目实际用到的 strapping 脚是 GPIO5（CSN）和 GPIO0（按键）。**
> GPIO5 上电时若被外部拉低，ESP32 会尝试从 SDIO 启动而失败。**nRF24L01 的 CSN 内部有上拉**，所以正常情况下没问题；但如果上电后串口完全无输出、板子反复重启，先拔掉 nRF 模块再上电试试——这是排查电源/上电时序的第一招。

## 4. 上电与检查顺序（照着做，别跳步）

### 第 1 步：只接 ESP32

插 USB，确认：
- 板载 LED 亮
- 电脑设备管理器出现串口（CP210x 或 CH340）
- Arduino IDE 能选到该串口

**不通就换 USB 线**（90% 是充电线，没有数据线芯）。

### 第 2 步：接 ICM20689（先不接 nRF）

只焊/插 I2C 四根线 **+ CS 到 3V3**，烧录固件，串口应出现：

```
OK   ICM20689 ready (id=0x98, gyro +-500dps, accel +-4g)
```

看到 `ERR ICM20689 init failed (WHO_AM_I=0x??, expect 0x98)` 就查（**先看括号里的实际值**）：
1. 万用表测 IMU 的 VCC-GND 是否有 **3.3V**（没电压 = 线断/面包板孔坏）
2. **CS 是否接到了 3V3**（ICM20689 特有；CS 悬空就永远没应答，读回 `0x00`）
3. SDA/SCL 是否接反（很常见，两者都是数据线，接反完全没反应）
4. SDO/AD0 是否真接地（用万用表通断档量到 GND）

> 读回 `0x68` 说明模块是 MPU6050 而不是 ICM20689；读回 `0xFF` 说明总线上什么都没有（没供电或线断）。

### 第 3 步：接 nRF24L01（**必须串上电容**）

- **先断电**再接，nRF 模块不带热插拔保护。
- 接完上电，串口应出现：

```
OK   nRF24L01 ready (ch=76, 250kbps, addr=GLV01)
```

看到 `ERR nRF24L01 init failed` 按顺序查：
1. **VCC 是不是真的 3.3V**（不是 5V，也不是 0V）
2. **有没有并 100µF 电容**
3. SPI 五根线（SCK/MOSI/MISO/CSN/CE）有没有接错或虚接
4. 换一块模块试（这类模块到手不良率约 5~10%）

### 第 4 步：接状态 LED 和按键

这两个是板载的，**不用接线**。确认：
- 正常运行时 LED 每秒闪一下（心跳）
- 按 BOOT 键，串口打印 `BTN  mode -> GIMBAL`

## 5. 焊接过渡（从面包板到手套）

面包板只能验证逻辑，**最终必须焊到洞洞板（万用板）或定制 PCB 上**，否则戴在手上必然是接触不良。

### 5.1 推荐做法：洞洞板 + 排母

```
┌─────────────────────────────────┐
│  万用板 5cm × 7cm               │
│                                 │
│  [ESP32 排母 15P × 2]           │
│                                 │
│  [ICM20689 排母 6~8P] [C 100µF] │
│        └ CS 用一根短线固定接 3V3  │
│                                 │
│  [nRF24L01 排母 2×4P]           │
└─────────────────────────────────┘
```

- **用排母而不是直接焊模块**：模块坏了能换，且排母比直接焊的机械强度更好。
- nRF24L01 建议用 **2×4 排母**（8 脚），不要用双排弯针。
- 100µF 电容**焊在排母背面、紧贴 1/2 脚（VCC/GND）**，这是唯一有效的位置。

### 5.2 走线规范

| 规则 | 原因 |
| --- | --- |
| 电源线（3V3/GND）用**粗线**，信号线用细线 | 电源要过 115mA 脉冲电流 |
| 3V3 和 GND **各走一条独立干线**，不要串联取电 | 避免地弹干扰 |
| I2C 两根线**绞在一起**（每 5cm 一绞） | 抗干扰；400kHz 下 20cm 以内不需要上拉（模块自带） |
| SPI 线尽量**短直**，长度 < 15cm | SPI 18MHz 时钟，长了会振铃 |
| 天线区域下方**不能走任何线**，尤其不能铺铜 | 2.4G 天线下方铺铜会把信号吸走 |

### 5.3 线材出口处理（防断线）

戴着手套的手会反复弯折线材，**这是手套端最高发的故障**：

```
        ┌────────────┐
        │  焊点      │
        │    │       │
        │  ▓▓▓▓      │  ← 热熔胶包住焊点（第一层保护）
        │  ░░░░      │  ← 热缩管套住线（第二层保护）
        │  ░░░░      │
        └────┼───────┘
             │  ← 线材在此处自然弯曲，不承受拉力
```

- 焊点先用**热熔胶**完全包裹（不是点一下，要包成一坨）。
- 外面套 **φ3 热缩管**，长度 15mm 以上，一端伸进胶里。
- 线材在出口处留 **2cm 松弛**，让弯曲发生在松的地方而不是焊点。

## 6. 常见接线错误对照表

| 现象 | 最可能的原因 | 检查方法 |
| --- | --- | --- |
| 串口完全无输出 | USB 线只有充电功能 / 板子没进下载模式 | 换线；按住 BOOT 再按 EN 复位 |
| `ICM20689 init failed` | SDA/SCL 接反；**CS 没拉高**；SDO/AD0 悬空；模块无电 | 看打印的 `WHO_AM_I`；量 3V3；CS 接 3V3；对调 SDA/SCL 试 |
| MPU 能初始化但数据不变 | I2C 时钟太快 / 线太长 | 代码里 `400000` 改成 `100000` |
| 姿态角度乱跳 | MPU 模块虚焊（电源脚） | 轻压模块看数据是否突变 |
| `nRF24L01 init failed` | 无电容、供电不足、SPI 接错 | 并 100µF；量 VCC；核对 5 根 SPI |
| nRF 能初始化但收不到 | 两端信道/地址/速率不一致 | 逐项核对 [分层说明](IMU人体姿态控制小车%20分层说明及具体实施步骤.md) §9.1 |
| 发几包就复位（串口重打 banner） | nRF 发射瞬间掉压 | 并 100µF + 换 STM32/AMS1117 单独供电 |
| LED 快闪但串口正常 | nRF 挂了（这是设计好的提示） | 查 nRF 供电 |
| 按 BOOT 键没反应 | GPIO0 悬空 / 按键坏 | 万用表量按键按下时是否导通到 GND |

更多现象见 [debug_faq.md](debug_faq.md)。

## 7. 与机器人端的连线差异（提醒）

手套端和车端**不共任何电气连接**，只通过 2.4G 无线通信。两端的 nRF24L01 配置必须完全一致：

| 参数 | 手套端（发射） | 车端（接收） |
| --- | --- | --- |
| 信道 | 76 | **76** |
| 速率 | 250kbps | **250kbps** |
| 地址 | 写管道 `GLV01` | 读管道 `GLV01` |
| CRC | 16 bit | **16 bit** |
| 负载 | 14 字节 | **14 字节** |
| 角色 | `stopListening()`（发送） | `startListening()`（接收） |

> 车端是树莓派，nRF24L01 接在 SPI0 上（CE=GPIO25 / CSN=GPIO8 是常见接法，需在 Python 里用 `spidev` 或 `nrf24` 库配置）。这部分由车端同学负责，但配置表必须和本表逐项对上。
